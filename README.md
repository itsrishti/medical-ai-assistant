🧠 Medical AI Assistant
AI-powered Streamlit app that analyzes medical images (X-rays, MRIs, CT scans) and generates diagnostic insights using Gemini 1.5 Flash.

🚀 Features
1.Upload & analyze medical images

2.Powered by Google Gemini 1.5 Flash

3.Detailed diagnostic summaries

4.Clean UI built with Streamlit

Tech Stack:
1.Frontend: Streamlit

2.Backend: Gemini API

3.Lang: Python

4.Image: PIL, Vision model
